# BPC 声卡授时

用电脑声卡模拟中国 BPC 电波授时，让收不到商丘授时台的卡西欧电波表在有线耳机旁边完成对时。

浏览器发不出 68.5 kHz。页面发射 13.7 kHz（或 17.125 kHz）载波，耳机线圈的非线性会产生手表要的 68.5 kHz 磁场。

## 打开

在这个目录执行：

```bash
python -m http.server 8765
```

浏览器访问 `http://127.0.0.1:8765/`。不要直接双击 `index.html`，否则对时请求会被拦住，页面只能退回电脑时钟。

打开后页面会依次询问苏宁、WorldTimeAPI 和 TimeAPI，取往返最快的一次，并用半个往返时间修正钟差。苏宁在浏览器里用脚本读取，因为普通请求会被跨域拦住。三个都失败时使用电脑时钟，状态会标红。

## 给手表授时

1. 插上有线耳机。蓝牙耳机没有这条磁场通路。
2. 系统音量开到最大，输出设备选这副耳机。
3. 点击「开始」。13.7 kHz 接近人耳上限，听不清也仍然在发射。
4. 耳机喇叭贴住表背，不要移动。
5. 手表进入强制接收，出现接收图标后保持大约 3 到 8 分钟。
6. 若失败：换载波频率或波形，勾选「反相」，或把延迟微调每次移动 20 毫秒再试。

默认包络与真实 BPC 一致：数据秒开头静音 0.1 到 0.4 秒，帧标志整秒满幅。「反相」改成开头发声，帧标志整秒静音。

## 自检

「自检」把当前这一帧编码后再解码，结果必须等于该帧起始的北京时间。编码测试：

```bash
node --test
```
