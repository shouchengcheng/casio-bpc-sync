# BPC 声卡授时

[English](README.en.md)

用电脑声卡模拟中国 BPC 电波授时，让收不到商丘授时台的卡西欧电波表在有线耳机旁边完成对时。已在卡西欧 5610 上验证成功。

浏览器发不出 68.5 kHz。页面发射 13.7 kHz（或 17.125 kHz）载波，有线耳机喇叭贴在表背时，线圈的非线性会产生手表要的 68.5 kHz 磁场。

## 打开

直接双击 `index.html` 用浏览器打开即可，不需要 Python，也不需要先启动本地服务。

打开后页面会自动向苏宁对时，并用半个往返时间修正钟差。状态栏应显示「时间来源：苏宁」。若苏宁失败，页面会退回电脑时钟并把状态标红，可点「重新对时」再试。

## 给手表授时

1. 确认页面已对上公网时间，状态不是红色。
2. 插上有线耳机。蓝牙耳机没有这条磁场通路。
3. 系统音量开到最大，输出设备选这副耳机。
4. 点击「开始」。13.7 kHz 接近人耳上限，听不清也仍然在发射。
5. 耳机喇叭贴住表背，不要移动。
6. 手表进入强制接收，出现接收图标后保持大约 3 到 8 分钟。按键位置因表款而异，以说明书为准。
7. 若失败：换载波频率或波形，勾选「反相」，或把延迟微调每次移动 20 毫秒再试。正值表示提前发射。

默认包络与真实 BPC 一致：数据秒开头静音 0.1 到 0.4 秒，帧标志整秒满幅。「反相」改成开头发声，帧标志整秒静音。

## 自检

「自检」把当前这一帧编码后再解码，结果必须等于该帧起始的北京时间。编码测试：

```bash
node --test
```
